# Шпаргалки

## 🐋 База данных Docker

### 1️⃣ Проверить запущенные контейнеры

```bash
docker ps
```

_Вывод:_

```
CONTAINER ID   IMAGE         PORTS                    NAMES
3a1c7e1b28a9   postgres:15   0.0.0.0:5432->5432/tcp   my_postgres
```

---

### 2️⃣ Зайти внутрь контейнера

```bash
docker exec -it my_postgres bash
```

---

### 3️⃣ Подключиться к базе данных

```bash
psql -U postgres
```

или к конкретной базе:

```bash
psql -U postgres -d bot
```

---

### 4️⃣ Основные команды в psql

| Команда                         | Описание                    |
| ------------------------------- | --------------------------- |
| `\l`                            | Список всех баз данных      |
| `\c bot`                        | Подключиться к базе         |
| `\dt`                           | Список таблиц               |
| `\d users`                      | Структура таблицы `users`   |
| `SELECT * FROM users LIMIT 10;` | Просмотреть первые 10 строк |
| `\q`                            | Выйти из клиента psql       |
